What this means

Cross-Origin Resource Sharing headers decide which other websites may read this site's responses from a visitor's browser.

Why it was flagged

The server copied an arbitrary, unrelated Origin into Access-Control-Allow-Origin, and also sent Access-Control-Allow-Credentials: true. A malicious site can therefore make requests as a logged-in visitor and read the responses.

Remediation

Method and limits

  • Non-destructive. Every check sends benign, read-only requests (GET, HEAD, OPTIONS, TLS handshakes, DNS lookups) and analyses the response. Nothing was modified, and file contents and secrets were not extracted: evidence excerpts are short and secret values are masked.

  • Classification. Each finding is mapped to a CWE weakness and, through that CWE, to its OWASP Top 10:2025 category.
  • Severity. Ratings are CVSS v3.1 base scores for the weakness in general. Adjust them for what this system holds and who can reach it.
